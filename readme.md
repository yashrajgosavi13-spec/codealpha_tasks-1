# Basic Chatbot Using Python

## Description

This is a simple rule-based chatbot developed using Python. It takes user input and provides predefined responses based on specific words or sentences.

The chatbot can respond to greetings, answer how it is, tell its name, and exit when the user enters `bye` or `goodbye`.

## Features

* Responds to greetings like `hi`, `hello`, `hii`, and `hey`
* Responds to `how are you`
* Answers `what is your name`
* Handles unknown messages
* Allows the user to exit using `bye` or `goodbye`

## Python Concepts Used

* Functions
* `while` loop
* `if-elif-else`
* Lists
* User input
* `.lower()` string method
* `break` statement

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code or another Python editor.
3. Open a terminal in the project folder.
4. Run:

```bash
python basic_chatbot.py
```

5. Enter a message when prompted.

## Example

```text
Simple Chatbot
Type 'bye' to exit.

You: hi
Bot: Hi! How are you?

You: what is your name
Bot: My name is basic Chatbot.

You: bye
Bot: Goodbye!
```

## Limitations

This is a rule-based chatbot, so it can only respond to predefined inputs. It does not use AI or machine learning.

## Conclusion

This project demonstrates the basic concepts of Python by creating a simple interactive chatbot using functions, loops, conditions, lists, and user input.
